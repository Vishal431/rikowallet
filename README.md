# RikoWallet

Premium Laravel wallet website/API/admin with a Flutter companion app.

Fresh-server instructions: [Ubuntu/Nginx/MySQL setup](docs/SERVER-SETUP.md).
Create a production admin using `php artisan riko:admin-create YOUR_EMAIL`;
password entry is hidden and no default production credentials are shipped.

## Project layout

- `app/`, `routes/`, `resources/`, `public/`: Laravel at the project root.
- `flutter_apk/`: Flutter Android/iOS app source.
- `docs/INTEGRATION-GUIDE.md`: agreed scope and security invariants.
- `docs/DEVELOPMENT-STATUS.md`: current implementation and launch dependencies.
- `design/premium-v3/`: design references; `design/implementation/`: actual website screenshots.

## Local website

PHP 8.2+, Composer, MySQL 8+/compatible MariaDB, BCMath, mbstring, OpenSSL and PDO MySQL required.

```powershell
C:/xampp82/php/php.exe artisan serve --host=127.0.0.1 --port=8010
```

Open http://127.0.0.1:8010 . Sign-in: /login; admin: /admin.

Local credentials are generated by the sandbox seeder and stored privately in `storage/app/local-demo-credentials.txt` (ignored by Git). Do not reuse them in production. The local database is `rikowallet`; no real funds or provider credentials are configured.

For a new environment, install Composer dependencies, copy .env.example to .env, configure a dedicated database, run `php artisan key:generate`, then `php artisan migrate`. Only run `php artisan db:seed` in a local sandbox. The seeder refuses production and never overwrites existing users.

The website uses Blade and local CSS/JS, so a Node build is not needed to render it. Configure a web server's **document root to public/**; never serve the project root directly. A defensive root .htaccess is included for Apache, but proper document-root isolation remains required.

## Flutter

```powershell
cd flutter_apk
C:/dev/flutter/bin/flutter.bat pub get
C:/dev/flutter/bin/flutter.bat run --dart-define=API_BASE_URL=http://10.0.2.2:8010/api
C:/dev/flutter/bin/flutter.bat build apk --debug
```

10.0.2.2 reaches localhost from an Android emulator. For a physical device, use a reviewed reachable development endpoint; the local web server intentionally listens on loopback. Release builds require HTTPS and the production API base URL; do not ship the default development endpoint. Debug builds permit local cleartext traffic only. Release signing credentials are not included.

## Task partner callbacks

POST `/api/earn/verify-code` or `/api/earn/verify`.

Body: `user_code` (one-time session pairing code), `package_name`. Headers:
- X-Riko-Timestamp: Unix seconds, within five minutes.
- X-Riko-Event: immutable 16–100 character event ID.
- X-Riko-Signature: HMAC-SHA256 hex of timestamp + newline + event ID + newline + exact URL path + newline + raw body, signed with RIKO_CALLBACK_SECRET.

No test bypass or client reward amount is accepted. Pairing starts only for enabled, eligible tasks with a trusted provider. The seeded example tasks intentionally have no provider connected.

## Scheduler

Run `php artisan schedule:run` each minute. Daily statistics: 00:15 Asia/Kolkata; eligible pending rewards: every five minutes; monthly contest: first day at 00:30. Manual commands: `riko:stats`, `riko:rewards`, `riko:contest`.

Admin /admin/cron documents installation. Optional POST `/api/cron/run` requires RIKO_CRON_SECRET and signed timestamp/nonce headers; no secret-bearing query-string URL is provided.

See DEVELOPMENT-STATUS before using any feature with real funds.
